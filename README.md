# 돌고래 대시

행사장 부스에서 쓰는 미니게임입니다. 지오메트리 대시처럼 화면이 오른쪽으로 흘러가고, 돌고래가 바닷속 장애물을 피해 골인 지점까지 가야 합니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 빌드 과정이나 외부 이미지 에셋은 없습니다. 글꼴(Jua, IBM Plex Sans KR)만 Google Fonts에서 받아오며, 오프라인이면 시스템 글꼴로 대체됩니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| 클릭 / 터치 / 스페이스바 | 점프 (공중에서 한 번 더 누르면 2단 점프) |
| R | 현재 판 즉시 재시작 |
| Esc | 처음 화면으로 (시도 횟수 초기화, 다음 관람객용) |

## 장애물

- 성게, 해파리, 낚싯바늘: 닿으면 처음부터 다시 시작
- 노란 산호 바위: 위에 올라탈 수 있음, 옆면에 부딪히면 실패

## 구조

모든 코드는 `index.html` 하나에 들어 있습니다.

- 물리 상수: `SPEED`, `G`, `V1`, `V2` (단위: 타일, 초)
- 맵: `spike()`, `block()`, `jelly()`, `hook()` 호출 목록, 골인 위치는 `GOAL`
- 그리기: `drawDolphin`, `drawUrchin`, `drawJelly`, `drawHook`, `drawBlock`, `drawBackground`

현재는 이미지 에셋 없이 코드로 그린 초안입니다. 에셋이 준비되면 각 `draw*` 함수를 이미지로 교체하면 됩니다.
